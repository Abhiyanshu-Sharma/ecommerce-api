# E-Commerce REST API

Backend for an e-commerce application built with Node.js and Express.js.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Stripe

## Features

- User authentication
- JWT authorization
- Product CRUD
- MongoDB operations
- Stripe payment integration
- REST APIs

## Setup

npm install

Create a `.env` file using `.env.example`

npm run dev
